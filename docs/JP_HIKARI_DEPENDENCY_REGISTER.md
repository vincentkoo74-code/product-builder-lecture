## JP-BL-022 — 계정 삭제 후 참가 기록 잔존 (법적 판단 필요 / 구현 보류)

**실측된 현재 동작** (로컬 스키마 검증, 2026-09-02):

| 테이블 | 계정 삭제 시 |
|---|---|
| `auth.users` | 삭제 |
| `user_game_stats` | **CASCADE 삭제** |
| `user_game_history` | **CASCADE 삭제** |
| `participants` | **잔존 — 닉네임 포함** |
| `rooms` | 잔존 |

| # | 질문 |
|---|---|
| 1 | 계정 삭제 후 `participants` 의 **닉네임 잔존**이 허용되는가 |
| 2 | 허용되지 않는다면 **익명화**와 **행 삭제** 중 무엇이 요구되는가 |
| 3 | 법령상 **보존 기간** 요구가 있는가 (있다면 얼마인가) |
| 4 | 삭제 완료를 사용자에게 어떻게 고지해야 하는가 |

**기술적 선택지와 결과** (CRIS 기술, 선택은 하지 않음):

| 안 | 구현 | 결과 | 위험 |
|---|---|---|---|
| A 현행 유지 | 변경 없음 | 닉네임이 방 기록에 남는다 | 법령 위반 가능성 — 판단 필요 |
| B 익명화 | 삭제 시 해당 참가자 행의 `name` 을 비식별 값으로 치환 | 게임 기록 구조 보존, 식별성 제거 | 진행 중 방에서 표시명이 바뀐다 |
| C 행 삭제 | 참가자 행 삭제 | 완전 제거 | 진행 중 라운드의 판정 집합이 바뀔 수 있다(CORE 영향) |

⚠️ **CEO 지시로 어느 것도 구현하지 않았다.** B·C 는 CORE 게임 동작에 영향을 주므로 승인 후 별도 슬라이스가 필요하다.

**현재 사용자 대면 문구는 "모든 게임 기록이 완전히 삭제된다"고 주장하지 않는다** — JP-BL-022 가 해소될 때까지 그렇게 주장하지 않는다.
