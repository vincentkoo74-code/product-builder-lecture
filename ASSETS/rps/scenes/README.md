# RPS Cat Scene Images

Transparent PNG images for VS Code / web app use.

Recommended path in your project:

```txt
public/assets/rps/scenes/
```

Example usage:

```tsx
<img src="/assets/rps/scenes/cat-waiting.png" alt="waiting" />
<img src="/assets/rps/scenes/cat-lost-tired.png" alt="lost" />
<img src="/assets/rps/scenes/cat-win-happy.png" alt="win" />
<img src="/assets/rps/scenes/cat-draw-confused.png" alt="draw confused" />
<img src="/assets/rps/scenes/cat-decision-waiting.png" alt="decision waiting" />
<img src="/assets/rps/scenes/cat-ready-idea.png" alt="ready idea" />
```
